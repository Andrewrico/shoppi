# Credits

Shoppi combines and extends:

- **Jam11ty** (this repository's earlier life, up to v0.9, MIT; the old theme and all its history are archived on the `archive/v1.0` branch; it was briefly named Shopless): the Eleventy starter theme. Carried over: design-token approach, navigation data, CMS config and service-worker idea, blog structure.
- **Eleventify** (the theme behind andrewrico.com, MIT): the accessibility widget, on-page chat idea, structured data and `llms.txt` approach. Rewritten here as store-agnostic code; no site-specific content, branding or integrations were copied.

Both are by Andrew Rico and are MIT licensed, as is this project.

The site [andrewrico.com](https://andrewrico.com) is built on the Eleventify theme, the same lineage as this project.
